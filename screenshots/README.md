# MikołajRej: application screens and saved readings

Twelve visual examples: three owner-provided application views, three saved diary-page readings and six saved codex-line readings. The owner explicitly requested publication of the supplied application screenshots. They show real application runs, including historical version labels; not every original view is E26.

The nine remaining screens are screenshots of a static preview of already saved E26 results. They do not represent a new inference run or a new independent test. Three diary pages come from the existing D17 diagnostic; six codex lines are the first two identifiers from each of Psałterz, Rozmyślanie and Ortyle in the known RAW110 pseudo DEV diagnostic. No selection by error score was made. Machine outputs, including errors and empty line slots, have not been manually corrected.

Diariusz: historical manuscript identified by the owner as public domain, AGAD, Radziwiłł Archive VI, II-80a. Codex examples: Biblioteka Narodowa / Polona objects whose saved IIIF manifests mark them as public domain. Sources, hashes, actual RAW/LM outputs and geometry are recorded in readings.json; no reference transcriptions or local/private paths are included. The preview screenshots are presentation views of recorded outputs, not a claim of independent generalization.
